# Historical desktop measurements

Files in this directory are dated, immutable captures from the Electron-to-
Tauri/Rust migration. They preserve the command output, paths, identifiers,
toolchain versions, and machine conditions that existed when each capture was
taken. Those details are historical evidence, not a description of the current
repository layout or runtime.

Do not rewrite an existing capture to match current code. Add a new dated
Markdown summary and raw JSON capture for a new measurement, then reference it
from [Desktop Performance Baseline](../desktop-performance-baseline.md).
