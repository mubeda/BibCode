# Historical Superpowers Artifacts

The `specs/` and `plans/` trees contain dated design and execution artifacts.
They are retained as immutable engineering history, not as current instructions,
architecture documentation, or backlog state.

Paths, commands, statuses, and unchecked tasks may describe an earlier repository
layout or implementation phase. Before using a decision, verify it against the
current source, tests, and living documentation. Preserve the original bodies;
record new decisions in current documentation or a new dated artifact rather
than rewriting history. Mechanical formatting or link repairs are allowed only
when they do not change the recorded meaning.
