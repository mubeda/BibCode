Design: [`2026-10-27-inbox-design.md`](../specs/2026-10-27-inbox-design.md).
Branch `claude/b3-inbox` from `origin/develop` at `27702287cc`.

## Acceptance criteria (from the issue)

1. The toggle shows Environments | Repositories | Inbox, each with an icon,
   keyboard and a11y accessible like today.
2. Inbox shows four tiles (All Agents, Needs Attention, Working, Done) with
   live counts matching agent statuses.
3. Clicking a tile selects it (only one, `aria-pressed`) and filters the list.
4. Clicking an agent opens its worktree area focused on that agent: the chat
   panel for chat agents, the AI terminal for terminal agents.
5. Selected view and tile persist across reloads.
6. Unit tests cover the category mapping and toggle/tile selection;
   Environments and Repositories behave as before.

## Changes

1. **Store** (`uiStateStore.ts`): add `"inbox"` to `SidebarView`; add
   `InboxCategory`, `inboxCategory: InboxCategory | null`, `setInboxCategory`;
   parse/persist both with strict value checks. Update
   `Sidebar.testHarness.tsx` store mock types.
2. **Logic** (new `components/sidebar/inbox/inbox.logic.ts`):
   `INBOX_CATEGORIES` (id, label, groups), `countInboxCategories(rows)`,
   `selectInboxRows(rows, category)` (recency order),
   `resolveDefaultInboxCategory(counts)`, `resolveInboxOpenTarget(row,
   centerState)` returning `{ hostRef, focus: chat-panel | host-chat |
   ai-terminal | none }`, and `isInboxRowCurrent(...)` for the selected row.
3. **Rows hook** (new `inbox/useInboxAgentRows.ts`): the AgentsPage row build
   (checkouts, live branches, `buildAgentRows`) composed from the existing
   exports, plus `useAgentsUnread(rows)`.
4. **View** (new `inbox/SidebarInboxView.tsx`, `inbox/InboxCategoryTiles.tsx`):
   tiles, list, loading and empty states, open handler (markRead, set active
   environment, focus surface via the center-panel store, navigate to the host
   route, close the mobile sidebar).
5. **Toggle**: third option, `grid-cols-3`, container-query label hiding with
   `title` fallback.
6. **Switch points**: `Sidebar.tsx` renders `SidebarInboxView` for `"inbox"`,
   hides the context card, and `SidebarChromeHeader` reserves the rail strip
   for any non-Environments view; `AppSidebarLayout.tsx` shows the rail only
   for Environments.
