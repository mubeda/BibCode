# BiBCode v0.3.8 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish BiBCode v0.3.8 from `main` with complete release notes, a green two-stage stable release workflow, and every supported installer and updater asset attached.

**Architecture:** Use the repository-owned `.github/workflows/release.yml` stable workflow rather than assembling installers locally. Merge the verified feature history into `main`, create and inspect the workflow-generated draft, replace its generated body with a curated summary of `v0.3.7..v0.3.8`, then run the workflow's explicit publication approval path and verify the finalized release remotely.

**Tech Stack:** Git, GitHub CLI, GitHub Actions, Vite+, Rust, Tauri 2, GitHub Releases.

## Global Constraints

- Publish the numeric stable version `0.3.8` with tag `v0.3.8`.
- Merge and push only after the complete local verification gates pass.
- Preserve the host-owned worktree at `/Users/admin/.codex/worktrees/c405/BibCode`.
- Use the workflow's two-stage stable draft and approval process.
- Require macOS arm64 DMG, macOS x64 DMG, Linux x64 AppImage, and Windows x64 NSIS installers.
- Require signed updater payloads plus `latest.json` with exactly `darwin-aarch64`, `darwin-x86_64`, `linux-x86_64`, and `windows-x86_64` targets.
- Never print or persist updater signing secrets.
