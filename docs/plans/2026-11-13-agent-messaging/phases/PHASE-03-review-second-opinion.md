# Phase 3: Review, Second opinion and the answer notice

- Goal: A person asks another agent for a review of this checkout or for a second opinion on the last answer, sees what is attached and what is left out, and when the answer arrives gets a notice in the source that survives a reload, marks the thread unread and offers Bring back, which drafts the quoted answer and sends nothing, with web tests and the UI.md and React reviews recorded.

- Must not touch: `apps/server/**`; `packages/**`; `apps/web/src/components/ThreadTerminalPanel.tsx` (phase 9); `apps/web/src/components/sendToAgent/handoff.logic.ts` and `outOfTokens.logic.ts` (phase 4); `apps/web/src/components/chat/**` and `apps/web/src/components/settings/**` (phases 2 and 7); `apps/web/src/codeReview.ts` (reviewed and left unchanged unless a test of task 3.1 shows `resolveCodeReviewPrompt` cannot serve as the builder).
- Skills: tdd (red-green discipline for every task); vercel-react-best-practices (render, hook and memo rules for every changed component, reviewed in each task's last step); ui-ux-pro-max (scope picker, warnings and notice layout and states); better-accessibility (radio group keyboard use, polite announcement of a new notice, focusable disabled controls with their reason)
